# Future Spriggit source

This directory holds the pinned Spriggit translation configuration for Starfield.
There are **no committed YAML records** yet; no source ESM may be inferred from it.

\`.spriggit\` describes known master style so Spriggit can eventually resolve
\`Starfield.esm\` references in a build environment without game files. It does
**not** provide armor record data from version 1.16.244, or replace the actual
master for reference-by-reference compatibility comparison.

Do not serialize or commit the original author's 2024 Transmog plugin here.
